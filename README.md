# TH/EMIS Mac releases

Signed builds of the TH/EMIS Mac apps used by colleagues, and the small files the apps read to
offer updates. No source code and no data here.

- `brian.json` — TH/EMIS Studio
- `nino.json` — TH/EMIS Facturation

Each release's zip is signed (Ed25519); the apps refuse an update whose signature does not match.
